HOW TO ADD YOUR PUBLICATIONS
============================

1. Put each PDF in this folder (magazine/pdfs/) using the file names already listed
   in magazine/publications.json, for example:

     meca-newsletter-2026-06.pdf
     meca-newsletter-2026-05.pdf
     meca-newsletter-2026-04.pdf
     meca-newsletter-2026-03.pdf
     meca-newsletter-2026-02.pdf
     meca-newsletter-2026-01.pdf
     meca-insights-2026-05.pdf
     meca-insights-2026-04.pdf
     brochure-dismissal-survive-court-2026-08.pdf
     brochure-misconduct-domestic-inquiry-2026-06.pdf

2. Redeploy the site. Each card switches from "Coming soon" to its real cover
   and opens in the flip reader automatically.

ADDING A NEW ISSUE
Copy one block in magazine/publications.json, change title / issue / group / pdf,
and drop the matching PDF in this folder. The newest issue should go at the top.
"note" is optional (a one-line caption under the card).

TIP: Keep each PDF under ~15 MB (export from InDesign as "Smallest File Size"
or "High Quality Print" downsampled to 150 ppi) so pages turn quickly on phones.
